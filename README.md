# Iddio

Security gateway that sits between AI agents and Kubernetes clusters. Classifies every kubectl operation, enforces per-agent policy, and logs everything with a tamper-evident audit trail.

## Installation

### Homebrew (macOS / Linux)

```sh
brew install leonardaustin/tap/iddio
```

### Download binary

Pre-built signed binaries for macOS and Linux are available on the [Releases](https://github.com/leonardaustin/iddio/releases) page.

### Docker

```sh
docker pull ghcr.io/leonardaustin/iddio:latest
```
